# vault-obsidian

Small Obsidian vault written by hand for the Obsidian importer and link
compatibility (PLAN Part 2, K2, K15). It covers `.obsidian/` settings, folder
notes, `[[link|alias]]`, `[[note#heading]]`, `[[note#^block]]`, `![[embed]]`,
front matter `aliases` and `tags`, inline `#tags`, callouts, attachments and a
template folder. Each note has a `fixture` property saying what it tests.
